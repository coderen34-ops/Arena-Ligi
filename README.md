# Arena Ligi

Paper 26.2 / Java 25 için 1v1 arena ligi eklentisi: dövüşçü kaydı ve lakap, ligler ve puan, otomatik maçlar, eşit kit, bahis.
MeslekSistemi'nin bankası ve kasasıyla sadece `MeslekAPI` üzerinden konuşur (`depend: [MeslekSistemi]`).

Derleme: önce Meslek-Sistemi'nde `mvn install`, sonra burada `mvn package`.
